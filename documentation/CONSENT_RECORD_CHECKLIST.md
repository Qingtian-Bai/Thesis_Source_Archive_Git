# Consent-record handover checklist

This checklist does not replace participant consent records.

- [ ] Confirm with the supervisor whether university ethics approval or exemption was required.
- [ ] If a genuine approval or exemption exists, add its correct reference to the dissertation and handover record.
- [ ] Confirm that each participant's actual consent record is securely retained outside the public technical package.
- [ ] Confirm the supervisor or authorised assessor can access those records through an approved route if required.
- [ ] Do not place signed forms or other personal data in a public or routinely shared source-code archive.
