# Thesis Technical Freeze: 6FE329 (18 August 2026)

This repository preserves the code, launcher, configuration, tests and integrity records for the frozen technical release. The original private freeze also contained two custom weights, YOLO pose and COCO weights, an input recording, regression logs and retained visual evidence. Those binaries and media are not published in this repository.

- Door v5 provides authoritative mobile-phone alerts.
- The later custom weights provide paper and note context only.
- The 6FE329 result on the existing recording is labelled as a post-test engineering regression, not as a new independent test.
- `FROZEN_MANIFEST.json` records the key conclusions and file-level SHA-256 values.
- `SHA256SUMS.txt` records byte-level integrity values for the complete private freeze, including files intentionally excluded from GitHub.

The tagged source states and their integrity records are archival evidence. Further development should be performed on a new branch rather than by rewriting the preserved tags.
